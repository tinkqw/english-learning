# 英语表达采集（翻译 / 润色 → gaps.jsonl）

这是一个 Claude Code skill：放进 `~/.claude/skills/english-collect/` 即可使用。

## 做什么

用户让你做翻译（中文→英文）或润色（英文→英文）时，**先把主任务做完、把稿子交给用户**；然后在同一轮内顺手判断有没有值得练的表达，有就落盘，没有就不落。**全程不向用户追问**（不问「要不要记」「哪个词不会」——采集不加步骤）。

## 选块标准

优先级：**功能表达**（委婉反对、确认理解、拉回主题、推进表态）→ **业务搭配**（rollout / top of funnel 这类）→ **必要的单词**。

按模式收：

| 模式 | 判定 | 收什么 |
|---|---|---|
| 翻译（中→英） | 弱信号 | 每条最多 1–3 个有工作价值的表达，**允许为 0** |
| 润色（英→英） | 强信号 | 只收**必要纠错**、**明显缺失或无法表达**的说法；可选的风格替换（语义语法已成立的改写）**不收** |

判断口径：不是「这里改动了吗」，而是「用户自己说得出这个表达吗」。早就会说的不收。

## 落盘格式

append 一行 JSON 到 `$ENGLISH_DATA_DIR/gaps.jsonl`（默认 `~/Data/english-learning/gaps.jsonl`）：

```json
{"ts": "<UTC ISO>", "source": "slack", "mode": "translate|polish", "zh": "<中文原意，翻译模式才有>", "en_draft": "<润色模式的用户原稿，翻译模式留空>", "en": "<最终英文稿里的对应句>", "chunks": ["<英文语块>"], "scene": "<一句中性场景概括>"}
```

- `scene` 当场写：一句中性中文（如「和 PM 讨论发布策略」），**不含同事姓名、公司内部名、敏感细节**——夜间造卡只送语块 + 这句场景，原文不出本机。
- `chunks` 是最终稿里挑出的英文语块（短语或句型，不是整句）。
- `ts` 用 `date -u +%Y-%m-%dT%H:%M:%S+00:00` 取。

## 边界

- 落盘成功与否都不改变给用户的回复主体；不汇报「已帮你记下」之类的额外话术，除非用户问。
- 拿不到值得收的表达就什么都不写，不凑数。
- 本 skill 只管写 gaps.jsonl；造卡由 `learning/process-gaps.py` 夜间完成，学习在聊天会话里（`learning/session.py`）。
